## 決定ログ（今回のセッションで決めたこと）

### スコープ外にしたもの
| 項目 | 理由 |
|---|---|
| 受入れ初めて/受入れ済（E13） | スコープ外 |
| 書類の郵送先住所（B24/D24/E24） | スコープ外 |
| 決算状況12欄（経常損益・純損益・純資産・過年度売上） | スコープ外 |
| 前1年間の行方不明者数（特定技能・技能実習） | スコープ外 |
| 所属役員一覧（氏名/ふりがな/役職） | スコープ外 |
| 協力確認書ブロック（提出方法・提出日・担当者連絡先・メール・市区町村） | このExcel経由では対応しない。**提出時に担当者がapp216へ手動登録**する運用 |
| 水道光熱費の徴収有無・金額（居住費の詳細 16行目以降全体） | スコープ外。その他定期負担費用ブロック（共済会費等のサブテーブルマッピング含む）も含めて対象外 |
| **app36マスタ_事業所（全23行）** | **事業所は内定時に別フローで既に登録済みのため、このExcelマッピングの対象外** |
| ア住居マーカー3種（アa/b/c、支援計画書1-17号用） | 今回のExcelマッピングでは対応しない（雇用条件書側のCHECK_BOXのみ対応） |

### 対応する（新規対応/運用ルール決定）もの
| 項目 | 決定内容 |
|---|---|
| ※月給・日給の場合の1時間当たりの金額（1-6別紙:R6） | `_1_4_1_1時間あたりの金額` へ対応（本表に追加） |
| ※日給・時間給の場合の1か月当たりの金額（1-6別紙:R7） | `_1_4_2_１ヶ月あたりの金額` へ対応（本表に追加） |
| 作成責任者氏名のふりがな（1-4:E76/I76） | **新規フィールド追加は不要。** app39で本人が未登録なら登録し「【ビザ関連の担当区分】書類作成責任者」をチェック。app55は「連絡先ID（資料作成者）」ルックアップで対応（代表者も同様に担当区分「代表者」＋「連絡先ID（代表者）」ルックアップ） |
| その他特記事項（【介護分野】事業所概要1:A19） | app55 `_2その他特記事項` へ対応（app36対象外化に伴いapp55側に振替） |

### 値変換・入力元の仕様を確定したもの
| 項目 | 決定内容 |
|---|---|
| 労働保険番号・雇用保険適用事業所番号 | **Ⅲ事業所単位（E29/G29）を正入力**とする |

| 作成日と署名日の対応 | 同一視して問題なし |
